*Scanny*
Android-приложение для распознавания текста с изображений.
Возможности:
* Загрузка изображений из галереи
* Распознавание текста на русском и английском языках
* Сохранение истории сканирований
* Копирование и экспорт результатов
* Светлая и тёмная тема
* Работа без интернета

Установка
Скачать APK из раздела Releases и установить на устройство.
При установке разрешить установку из неизвестных источников.
